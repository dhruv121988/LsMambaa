01

VMamba-Tiny 2D-SSM Encoder

Params: 24.1M

Replaces standard self-attention with 2D Selective Scan (SS2D). Traverses spatial patches across four diagonal and cardinal directions, achieving linear O(N) computational complexity while preserving continuous global receptive fields.

State Space Continuous Formulation

h'(t) = A h(t) + B x(t)

y(t) = C h(t) + D x(t)

Discretization with Input-Dependent Δ

Ā = exp(Δ A),   B̄ = (Δ A)-1 (exp(Δ A) - I) Δ B

  • • Stages 1-4 Feature dims: [96, 192, 384, 768]
  • • SSM State Expansion: d_state = 16
FLOP Scaling: Ο(HW) vs Ο((HW)²)
02

Boundary Gating Module (BGM)

Proposed Core

Eliminates boundary semantic ambiguity between visually similar classes (e.g. Building vs. Road) by dynamically modulating low-level spatial features using filtered boundary edge activations prior to concatenation.

Gating Transformation Rule

F̂skip(l) = Fskip(l) ⊙ (1 + γ · tanh(Wb · Bfeat(l)))

Boundary Modulator Layer

Bfeat(l) = Conv1×1(σ(Conv3×3(B(l))))

  • • Suppresses interior over-segmentation while enforcing sharp land contours.
  • • Learnable parameter γ controls boundary modulation strength.
Boundary-F1 Gain: +4.28% over Vanilla VMamba
03

Progressive Boundary Supervision

Auxiliary Heads: 4

Hierarchical coarse-to-fine edge extraction. Prevents vanishing gradients in deep encoder layers by enforcing explicit morphological boundary reconstruction at 1/32, 1/16, 1/8, and 1/4 feature scales.

Scale-Weighted Boundary Loss

Lbnd_total = ∑l=14 2-(4-l)} · [ LDice(Ybndl, Pbndl) + α LBCE ]

Class-Balanced Binary Formulation

LBCE = -β ∑ log Pbnd(i∈E) - (1-β) ∑ log(1-Pbnd(i∉E))

  • • Edge ground truths derived dynamically via Sobel filter during batch loading.
  • • Positive/negative edge pixel weighting factor: β = |Y_non_edge| / |Y|
Edge Localization Loss: Dice-Loss Weighted
04

Joint Multi-Task Loss Objective

λ_bnd = 0.40

Dual objective function combining cross-entropy classification, region-based Lovász-Softmax for continuous mIoU optimization, and auxiliary multi-stage boundary penalization.

Complete Objective Function

L = LCE(Y, Pseg) + LLovász(Y, Pseg) + λbnd · Lbnd_total

Lovász Extension for Jaccard Loss

LLovász = 1/|C| ∑c∈C ΔJ_c(m(c))

  • • Directly optimizes non-differentiable Intersection-over-Union (IoU).
  • • Multi-task gradient normalization ensures stable joint convergence.
